# Wall World LowHpAlarm mod

## Description
The mod adds 3 level of health warnings:
- Visual: red **vignette** (default 60hp, color, intensity and hp levels can be configured)
- Audial: alarm **sound** (default 40hp, hp level can be configured, sound file can be replaced (`BepInEx\plugins\LowHpAlarmResources\alarm.wav`))
- Act.. Actual.. Actional.. Making action one: automatically **opens the upgrade menu** (so you can repair the spider) and locks it from accidential closing for .5s. (default 20hp, hp level can be configured). Please, note that if you have let say 25 hp and get -30hp damage, menu won't be opened and you'll die. 
Warnings can be configured in the config file (`BepInEx/config/com.wallworld.lowhp.cfg`) or disabled.

## Installation instructions
• Install BlepInEx 5 (I tested with 5.4.23.4) in the game root folder
• Unpack archive in the root folder (so archive's BepInEx folder collide with existing BepInEx folder)
